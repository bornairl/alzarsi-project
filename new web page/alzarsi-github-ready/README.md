# Alzarsi Ltda. — sitio web

Sitio corporativo estático preparado para GitHub Pages.

## Publicación

1. Crea un repositorio en GitHub.
2. Sube `index.html`, `styles.css`, `script.js` y la carpeta `assets`.
3. Abre **Settings → Pages**.
4. Selecciona **Deploy from a branch**, rama **main** y carpeta **/(root)**.

El formulario de pedidos prepara un correo en el dispositivo del visitante. No almacena información.
